# Linux Satellite Ground Station

A Linux-based satellite ground station for receiving,
processing, and storing satellite signals and telemetry.

## Project Goals

- Learn Linux system administration
- Automate tasks using Bash
- Process satellite data using Python
- Run the application as a Linux systemd service
- Receive real satellite signals using SDR
- Store and process telemetry
- Add monitoring and observability
- Containerize the application
- Build a CI/CD pipeline
